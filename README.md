# Richmond estate sales, ranked

The page at **https://phillipspwood-creator.github.io/richmond-estate-sales/** lists in-person estate sales
within about 35 miles of downtown Richmond, Virginia, ranked by a quality score from 0 to 100.

It is rebuilt every morning around 7:00 Eastern. Each day's page replaces the last one.

Listings and photos belong to their sellers; every sale links to its original listing. Home values come from
public county assessment records.
